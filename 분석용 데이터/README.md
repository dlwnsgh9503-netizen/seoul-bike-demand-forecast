# 분석용 데이터

[대여소별 시간 데이터 샘플 보기](대여소_시간별_샘플.csv) · 2024년 7월 5일(금)~7일(일), 3개 대여소 × 72시간 = 216행. 저·중·고수요 그룹에서 대여소 번호가 가장 작은 곳을 한 곳씩 골라 주요 열 12개를 담았다.

## 샘플 CSV 열 설명

한 행은 **대여소 한 곳의 한 시간**이다. 아래 예시는 서울 시각 오전 9시에 다음 한 시간의 출발 건수를 예측하는 경우다. 유효 대여는 이용시간이 0분보다 길고 이동거리가 0m보다 긴 대여를 뜻한다.

| 열 이름 | 단위·값 | 의미 |
|---|---|---|
| `target_time` | 서울 현지 날짜·시각 | 예측 대상 한 시간의 시작 시각. 09:00인 행은 09:00부터 10:00 직전까지를 다룬다. |
| `station_id` | 대여소 번호 | 예측할 대여소의 고유 번호. 같은 시각의 대여·반납 자료를 이 번호로 연결한다. |
| `station_name` | 대여소명 | 선정표에 기록된 대여소 이름. 예를 들어 221번은 ‘여의도초교 앞’이다. |
| `demand_group` | `low`, `medium`, `high` | 2023년 1월~2024년 6월의 대여량으로 후보 대여소를 세 등분한 상대 등급. 각각 저·중·고수요이며, 같은 대여소에서는 시간대가 바뀌어도 등급이 같다. |
| `target_rentals` | 건 | **모델이 예측할 정답.** 09:00부터 10:00 직전까지 해당 대여소에서 실제 출발한 유효 대여의 최종 건수다. |
| `returns_prev_1h` | 건 | 08:00부터 09:00 직전까지 **이 대여소에 반납된** 건수. 분석 대상 50곳 밖에서 출발한 자전거도 포함한다. |
| `returns_prev_3h` | 건 | 06:00부터 09:00 직전까지 이 대여소에 반납된 건수. 직전 1시간의 반납도 이 합계에 포함된다. |
| `rentals_lag_1h` | 건 | 08:00부터 09:00 직전까지 **이 대여소에서 출발한** 유효 대여 중, 예측 시각인 09:00 전에 반납까지 확인된 건수다. |
| `rentals_lag_168h` | 건 | 7일 전 같은 시간대(09:00부터 10:00 직전)에 이 대여소에서 출발한 유효 대여 중, 이번 예측 시각 전에 반납까지 확인된 건수다. |
| `temperature_lag1h` | °C | 예측 시각보다 한 시간 앞선 08:00의 서울 기온 관측값. 같은 시각의 대여소들은 같은 값을 사용한다. |
| `precipitation_lag1h` | mm | 08:00 관측 시각에 기록된 서울 강수량. 0은 관측 강수량 0mm를 뜻하고 빈칸은 원본 관측값의 결측을 뜻한다. |
| `is_weekend` | 0 또는 1 | 예측 대상 날짜가 토·일요일이면 1, 월~금요일이면 0이다. 평일 공휴일도 이 열에서는 0이다. |

샘플 첫 행을 읽으면, 2024년 7월 5일 00시 기준 **여의도초교 앞**에는 직전 1시간 동안 1대, 직전 3시간 동안 총 5대가 반납됐다. 이어지는 00시부터 01시 직전까지 이곳에서 실제로 출발한 유효 대여는 0건이었다.

## 전체 데이터 파일

MLP·GRU 학습에는 아래 첫 두 파일을 사용한다. 두 파일 모두 2023~2024년의 50개 대여소를 한 시간 간격으로 기록했다. 노트북은 압축된 CSV를 직접 읽고 `station_id`와 `target_time`으로 결합한다.

| 파일 | 행 수 | 용도 |
|---|---:|---|
| [station_hour.csv.gz](station_hour.csv.gz) | 877,200 | 대여소별 시간당 유효 출발 건수, 과거 이용량, 기상·달력 피처 |
| [대여소별_직전_반납.csv.gz](대여소별_직전_반납.csv.gz) | 877,200 | 각 예측 시각 직전 1시간·3시간 동안 해당 대여소에 반납된 건수 |
| [Seoul_public_bicycle.csv](Seoul_public_bicycle.csv) | 81,018 | 2015~2024년 서울 전체 시간별 대여량과 기상·달력 자료. 모델은 이 자료에서 결합한 기상·달력 값을 사용한다. |
| [월별 제외 건수.csv](월별%20제외%20건수.csv) | 24 | 월별 원본 건수와 이용시간·이동거리 필터 적용 후의 건수 대조 |

**대여·반납 기록**은 서울특별시의 공공자전거 대여이력에서 집계했다. 개별 이력이 필요하면 서울 열린데이터광장의 2023년·2024년 ZIP을 내려받을 수 있다. 로컬 실험에 사용한 연도별 ZIP은 이용시간 또는 이동거리가 0인 기록을 제거한 가공본이다. [서울시 공공자전거 대여이력](https://data.seoul.go.kr/dataList/OA-15182/F/1/datasetView.do)

**서울 전체 이용량·기상 자료**는 Kaggle 사용자 lnoahl이 서울 열린데이터광장의 이용량과 기상청 ASOS 관측값을 결합한 자료다. 배포자는 공공누리 제1유형(출처표시)을 명시했다. [Kaggle 데이터셋](https://www.kaggle.com/datasets/lnoahl/seoul-bike-sharing-dataset) · [서울 열린데이터광장](https://data.seoul.go.kr) · [기상청 기상자료개방포털](https://data.kma.go.kr)

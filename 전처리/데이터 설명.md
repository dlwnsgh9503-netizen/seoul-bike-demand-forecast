# 따릉이 대여소별 1시간 수요 예측 데이터

`station_hour.csv.gz`의 한 행은 한 대여소의 서울 현지 시각 한 시간을 나타낸다. 예를 들어 `target_time`이 2024-10-01 08시이면, 08시부터 09시 직전까지 출발해 이용시간과 이동거리가 모두 양수로 확인된 대여 건수가 정답이다. 50개 대여소의 2023년 1월~2024년 12월 기록 877,200행에 대여 1,656,370건이 포함되어 있다.

```python
import pandas as pd

df = pd.read_csv("station_hour.csv.gz", parse_dates=["target_time", "weather_time"])
train = df.loc[df["split"].eq("train")].copy()
```

## 대여 건수와 중복 처리

입력은 이용시간 0분 또는 이동거리 0m를 제외한 86,690,523행이다. 같은 자전거번호·출발시각(초 단위)·출발 대여소가 반복된 경우, 하나의 대여로 집계했다. 17개 열이 모두 같은 행은 0건이었고, 다른 항목에 차이가 있는 추가 행은 7,702건이었다. 같은 자전거·출발시각에 서로 다른 출발 대여소가 기록된 사례는 0건이었다. 전체 대여소에서 집계한 대여는 86,682,821건이다. 월별 대조 결과는 `월별 집계 검증.csv`에 있다.

시간대 배정과 대여소 번호 처리는 실제 원천 파일로도 확인했다. 선정한 50곳의 2023년 1월 전체 37,200개 대여소·시간 조합에서 0분·0m 제외 전 출발 건수를 서울시 시간대별 이용정보와 비교했다. 37,198개 조합이 일치했고, 전체 합계는 원천 대여이력이 2건 많았다. [서울시 시간대별 이용정보](https://data.seoul.go.kr/dataList/OA-15245/F/1/datasetView.do)

## 대여소 선정과 시간 분할

2024년 6월 말까지 공개된 2022년 12월, 2023년 6월, 2023년 12월 현황표를 대조했다. 세 시점에 같은 번호가 있고 인접 시점의 이름·주소·행정구·설치일·거치대 구성·운영방식이 같으며 좌표 차이가 1m 미만인 대여소를 남겼다. 이 중 학습 기간에 7일 연속 유효한 대여가 없었던 곳을 제외하니 2,206곳이었다. 학습 기간 평균 대여량으로 세 집단을 나누고, 각 집단에서 대여소 번호순으로 등간격 추출한 기존 10곳씩을 유지했다. 나머지 후보 중 같은 방식으로 저수요 7곳, 중수요 6곳, 고수요 7곳을 추가했다. 최종 50곳 중 기존 30곳은 선정표의 `sample_group`으로 구분할 수 있다. 이 표본은 안정적으로 대여가 기록된 곳을 분석하기 위한 표본이다. 좌표·거치대·수요 집단과 학습 기간 통계는 `선정 대여소.csv`에 있다.

| 구간 | 예측 대상 기간 | 정답이 있는 행 | 대여 건수 |
|---|---|---:|---:|
| train | 2023-01-01 ~ 2024-06-30 | 656,400 | 1,243,171 |
| validation | 2024-07-01 ~ 2024-09-30 | 110,400 | 221,456 |
| test | 2024-10-01 ~ 2024-12-31 | 110,400 | 191,743 |

예측 대상은 기록된 유효 대여 건수다. 해당 대여소·시간에 유효한 출발 기록이 없으면 정답을 0건으로 집계한다. 하루 내내 0건이었던 경우는 389개 대여소·날짜(9,336시간)다. 이 중 382개는 필터 적용 전에도 출발 기록이 없었고, 7개는 원천 기록이 모두 0분 또는 0m 조건으로 제외됐다. 두 경우 모두 학습과 평가에 포함한다. 대여를 원했으나 자전거 부족이나 운영 중단으로 이용하지 못한 사람은 이 기록으로 파악할 수 없다. 해당 날짜 목록은 `대여기록 공백일.csv`에 보관한다.

## 열 사용법

| 열 | 의미와 사용법 |
|---|---|
| target_time, station_id | 예측 대상 시간의 시작과 출발 대여소 번호. 대여소별 이름은 선정표에서 번호로 연결한다. |
| target_rentals | 정답. 해당 시간에 출발한 유효 대여의 최종 건수. 877,200개 대여소·시간 모두에 0 이상의 정수가 있다. |
| split | 시간순 분할. 같은 대여소 집합으로 학습·검증·평가한다. |
| hour, weekday, month, is_weekend, is_holiday | 예측 대상 시간의 달력 정보. 요일은 월요일 0부터 일요일 6까지이며 공휴일 표시는 Kaggle의 해당 날짜 값을 따른다. |
| rentals_lag_1h ~ rentals_lag_24h, rentals_lag_168h | 각 시차의 한 시간 동안 출발해 예측 정시 **전에 반납까지 확인된** 유효 대여 건수. 168시간 전 값은 전주 동일 시간 기준선에 사용한다. GRU 입력은 24시간 전부터 1시간 전까지 시간순으로 배열할 수 있다. |
| rentals_mean_3h, rentals_mean_24h, rentals_mean_168h | 직전 3·24·168시간에 출발해 예측 시점까지 반납이 확인된 대여 건수를 각 창의 시간 수로 나눈 값. 데이터 시작 전까지 거슬러 가는 창은 결측이다. |
| weather_time | 사용한 관측 시각. 목표 시간보다 1시간 이른 값을 사용한다. 원본에는 실제 게시 시각이 없어 이 한 시간 시차를 가정했다. |
| 기상 변수명_lag1h, 기상 변수명_missing | 해당 관측 시각의 원본 값과 결측 표시(1이면 결측). 기본 실험은 기온·습도·강수량·풍속을 사용한다. 추가 입력 실험을 위해 이슬점·일조시간·일사량·적설·전운량·시정·지면온도도 보존했다. |

과거 대여 건수에는 예측 시점까지 확인된 출발 실적만 들어 있다. 반납 시각이 서로 다른 동일 출발 기록은 늦은 반납 시각을 적용했다. 이 계산은 반납과 함께 기록을 조회할 수 있다고 가정한다. 집계에 쓰인 예측 시점과 예측 대상 시간을 구분하므로 직전 시간의 최종 대여 건수와 직전 시간 입력값은 다를 수 있다. 시차 입력의 0은 당시까지 확인된 대여가 0건이라는 뜻이다.

기상 결측은 채우지 않았다. 결측을 지원하지 않는 MLP·GRU에 적용할 대체값과 스케일링 계수는 각 실험의 학습 구간에서만 구한다. 서로 다른 입력 조합의 성능은 같은 평가 행에서 비교한다. Kaggle의 서울 전체 대여 건수 `count`는 입력에 포함하지 않았다.
